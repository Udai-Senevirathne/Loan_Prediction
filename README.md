# Loan Prediction

A machine learning project for predicting loan approvals using data analysis and modeling in Jupyter Notebook.  
This repository is designed for exploring, preprocessing, and predicting loan outcomes using various machine learning techniques in Python.

## Features

- Exploratory Data Analysis (EDA) on loan datasets
- Data cleaning and preprocessing
- Feature engineering
- Building and evaluating machine learning models
- Visualization of results
- Interactive analysis using Jupyter Notebook

## Technology Stack

- **Jupyter Notebook:** Main environment for code, analysis, and visualization
- **Python:** Data manipulation and machine learning
    - Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn, etc.

## Getting Started

### Prerequisites

- [Python 3.x](https://www.python.org/downloads/)
- [Jupyter Notebook](https://jupyter.org/)
- Recommended: [Anaconda](https://www.anaconda.com/products/individual) for easy package management

### Installation

1. **Clone the repository:**
    ```bash
    git clone https://github.com/Udai-Senevirathne/Loan_Prediction.git
    cd Loan_Prediction
    ```

2. **Install dependencies:**
    - If using Anaconda:
        ```bash
        conda create -n loan_pred python=3.9
        conda activate loan_pred
        conda install jupyter pandas numpy matplotlib seaborn scikit-learn
        ```
    - Or with pip:
        ```bash
        pip install jupyter pandas numpy matplotlib seaborn scikit-learn
        ```

3. **Run the notebook:**
    ```bash
    jupyter notebook
    ```
    - Open the relevant `.ipynb` file in your browser and follow the instructions in the notebook.

## Usage

- All code, analysis, and results are contained within the Jupyter Notebooks.
- You can modify the notebooks to use your own datasets or experiment with different models.
